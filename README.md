# PDF 一括ダウンローダー — 製品サイト

Chrome拡張機能「PDF 一括ダウンローダー」のランディングページとプライバシーポリシー。
GitHub Pages で公開しています。

- `index.html` — 製品紹介・価格
- `privacy.html` — プライバシーポリシー（Chrome ウェブストアの掲載に必要）
- `activate.html` — 購入直後に開く、ライセンスの自動有効化ページ
- `demo/` — 試用ページ（PDFが8件並んだ架空の授業ページ）
- `img/` — 紹介ページの画面写真（日本語版と英語版）。実際のポップアップを試用ページの状態で撮ったもの
- `fonts/` — 見出しの英字と番号に使うフォント（Anton / JetBrains Mono、SIL OFL）。外部のフォント配信を読まないよう同梱

拡張機能のソースコードは別リポジトリ（非公開）で管理しています。
